# Digital Campus УрФУ

**Сайт:** https://slad-pyat.gitverse.site/urfu_digital_campus

Рабочий прототип цифровой экосистемы УрФУ для конкурса редизайна. Цель — заменить разрозненные сервисы и «стену ссылок» одним понятным маршрутом: абитуриент → студент → выпускник.

## Что внутри
- **Главная-коммутатор** — вход по роли и быстрый переход к нужным разделам
- **Калькулятор ЕГЭ** — подбор направлений по баллам и проходным УрФУ
- **Дашборд студента** — расписание, дедлайны, статусы заявок в одном экране
- **Сервисы кампуса** — справки, заявки, инфраструктура без поиска по десяткам сайтов
- **Тёмная / светлая тема**, мобильная навигация, кликабельные фильтры и модалки

## Зачем
Сейчас у УрФУ сильный бренд и слабая цифровая связность: информация есть, но путь к действию рвётся. Этот прототип показывает, как выглядит кампус, если интерфейс ведёт к результату, а не к следующему каталогу ссылок.

Основан на UX-исследовании (`UX_RESEARCH.md`): боли абитуриентов, студентов и сотрудников сведены в 10 стратегических экранов.
